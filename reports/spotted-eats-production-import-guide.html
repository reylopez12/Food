What the import does

  • Adds missing restaurants and updates matching directory records.
  • Includes only two source-guarded address cleanups: 800 West Tower Avenue for C'era Una Volta, and 2350 Saratoga St #166 for Vinyl. Context annotations were removed; street numbers, direction and unit were preserved.
  • Great China's official ZIP 94704 resolves its provider ambiguity. Great China and Vinyl have newly validated coordinates; all accepted evidence is revalidated by the generator.
  • Stops the whole batch if the existing duplicate/identity checks find conflicts.
  • No schema changes, deletions, or writes to other tables.
  • Preserves existing verification, ratings, review counts, promotions and subscriptions.
  • Leaves unresolved locations at (0,0). Census coordinates are street-address-range estimates, not verified businesses, rooftops or entrances.

Run the import

  1. Open your Replit project's Database → Production → My Data → SQL. Confirm you selected Production.
  2. Download the SQL file below, or copy its full contents, and paste into the SQL editor.
  3. Run the full script together, including BEGIN and COMMIT. Do not run it in separate parts.
  4. Check the returned status. IMPORTED means the import succeeded. BLOCKED_NO_CHANGES means no listings were changed; review conflict_details before proceeding.
  5. On an initially empty directory, expect 296 inserted, 0 updated, and 0 conflicts. Re-running after a successful unchanged import should report 0 inserted, 0 updated, and 296 unchanged.

These are writes to your live directory. Review the script before running it. Existing confirmed locations are retained when the supplied address and city are unchanged and the import has no replacement coordinates.

Confirm the result

Run this read-only query:

SELECT COUNT(*) AS listings,
  COUNT(*) FILTER (WHERE lat <> 0 AND lng <> 0) AS with_coordinates
FROM public.venues;

For an initially empty directory, expect 296 listings, 250 with coordinates and 46 unresolved locations. If existing records are present, use the import's counts and conflict report rather than assuming these totals.

Then check the live listings endpoint and the wheel. Cached listing responses can take up to five minutes to refresh. Nearby spins still require location permission, a selected distance, and a restaurant within that radius; the 46 unresolved locations cannot appear in nearby results.
